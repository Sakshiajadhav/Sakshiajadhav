### 🚀 Featured Projects

**[🩺 Cloud-Native Kubernetes System Health API](https://github.com/Sakshiajadhav/kubernetes-system-health-api)**
Flask-based health-monitoring API with `/health`, `/metrics`, `/ready`, `/live` endpoints. 3-stage GitHub Actions pipeline (test → build → deploy), 11 pytest unit tests, hardened Docker image (~95MB, non-root user), Kubernetes Deployment with liveness/readiness probes and ConfigMap-driven thresholds.

**[☁️ AWS Multi-AZ Infrastructure with Terraform](https://github.com/Sakshiajadhav/terraform-aws-infra)**
Multi-AZ AWS environment provisioned via Terraform — custom VPC, Application Load Balancer, Auto Scaling Group running a Flask app behind Gunicorn. Two-tier security architecture (ALB public, EC2 restricted to ALB-only traffic). Encrypted, versioned remote state on S3 with native locking.
**Status:** 🔄 Core infrastructure complete (VPC, ALB, Auto Scaling, remote state) — observability (Prometheus/Grafana) in progress.
